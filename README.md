# Mono TV — домашний экран в стиле Apple TV для Сбер ТВ

Быстрый, тёмный, «кинематографичный» Home Screen для телевизоров и приставок на «Салют ТВ»
(Sber TV, SberBox): крупные карточки, стеклянный Dock, плавный физичный фокус, управление только пультом.
Собственное оригинальное оформление — без копирования интерфейса Apple TV и без чужих логотипов.

## Гарантии безопасности

Это главное требование к проекту, поэтому оно зашито в код, а не только в документацию.

- Приложение **не отключает, не удаляет и не изменяет** ни один чужой пакет: ни штатный лаунчер
  `ru.sberdevices.starlauncher`, ни ассистента «Салют», ни сервисы Сбера, Wi-Fi, Bluetooth, HDMI, пульт,
  обновления. В коде нет ни одного вызова, способного это сделать.
- Единственное состояние компонента, которое приложение умеет менять, — включение **собственного**
  HOME-псевдонима `tv.monotv.launcher/.HomeAlias`, и только после подтверждения в диалоге.
- Системные настройки не записываются. Разрешения: `ACCESS_NETWORK_STATE` (значок сети),
  `QUERY_ALL_PACKAGES` (видеть установленные приложения — это и есть работа лаунчера) и необязательное
  `READ_TV_LISTINGS`. **Разрешения на интернет нет вообще** — приложение физически не может выйти в сеть,
  поэтому список приложений не может покинуть телевизор.
- Кнопка ассистента (`KEYCODE_SEARCH` на пульте Сбера), HOME, кнопки-ярлыки сервисов, громкость и питание
  приложением не перехватываются: оно потребляет только стрелки, OK, BACK и MENU.
- Заводские / инженерные / сервисные меню (`com.cvte.fac.*`, `ru.sberdevices.TvFactoryHelper` и др.) никогда
  не показываются и не запускаются — даже по прямой ссылке. Список: [docs/PACKAGES.md](docs/PACKAGES.md).
- Скрипты в `scripts/` не выполняют `pm disable`, `pm uninstall` чужих пакетов, `settings put`, `setprop`,
  `reboot`, root-команды и эксплойты. Роль HOME меняет только `scripts/set-home.sh` — после явного «ДА».

## Сначала — анализ устройства

Прошивки Сбера разные (Android 9, 11 и 13; 1–2 ГБ памяти; Amlogic и MediaTek), поэтому до любых изменений
стоит снять «паспорт» телевизора. Оба способа **только читают** данные.

**Через ADB** (если отладка включена — как её включить, описано в
[docs/DEVICE-ANALYSIS.md](docs/DEVICE-ANALYSIS.md)):

```bash
scripts/analyze-device.sh --connect 192.168.1.50
```

Отчёт попадёт в `device-report/<дата>/summary.md`: модель, Android и SDK, разрешение и плотность, память,
текущий лаунчер и все кандидаты на HOME, TV-приложения, системные пакеты Сбера и их назначение, TV-входы.

**Без ADB** — из самого приложения: установите Mono TV с флешки (способ А ниже), откройте
«Настройки → Система». Там видны модель, версия Android, экран, память и текущий домашний экран, а пункт
«Сохранить отчёт об устройстве» запишет полный отчёт в
`/sdcard/Android/data/tv.monotv.launcher/files/device-report.txt`.

## 1. Как собрать

Нужны JDK 17+ и Android SDK (platform 37, build-tools 37). Путь к SDK — в переменной `ANDROID_HOME` или в
`local.properties` (`sdk.dir=...`).

```bash
scripts/build.sh release
```

Готовый файл: `dist/MonoTV-<версия>-release.apk` (скрипт печатает размер, SHA-256 и проверяет подпись).
Варианты: `debug`, `release`, `both`. То же самое вручную:

```bash
./gradlew :app:assembleRelease
```

Для телевизора используйте **release**: он собран с R8 и заметно плавнее отладочной сборки на слабом
железе. Готовая сборка также лежит в репозитории в каталоге `dist/`.

Тесты и рендер скриншотов:

```bash
./gradlew :app:testDebugUnitTest
```

```bash
./gradlew :app:recordRoborazziDebug
```

Скриншоты появятся в `app/build/screenshots/`.

## 2. Как установить

Mono TV ставится как обычное приложение и появляется на штатном экране в ряду «Мои приложения».
Штатный экран остаётся на месте.

**Способ А — с USB-флешки, без ADB и без аккаунта разработчика.** Скопируйте APK на флешку, вставьте её в
телевизор, откройте файловый менеджер на домашнем экране, выберите файл и нажмите «Установить».

**Способ Б — через apps.sber.ru/my.** Загрузите APK под тем же Сбер ID, что и на телевизоре, затем
установите его из каталога: «Мои приложения → Загруженное».

**Способ В — через ADB.**

```bash
scripts/install.sh --connect 192.168.1.50
```

Скрипт проверит версию Android (нужен SDK ≥ 23), установит APK, заранее скомпилирует приложение
(`cmd package compile -m speed` — для плавности) и запустит его. Роль HOME он не трогает.

Проверка после установки (скриншот и прогон кнопок пульта со снимком после каждого шага):

```bash
scripts/screenshot.sh home
```

```bash
scripts/verify-dpad.sh
```

## 3. Как удалить

```bash
scripts/uninstall.sh
```

Если Mono TV был назначен домашним экраном, скрипт сначала вернёт штатный, затем удалит приложение и
покажет, кто теперь отвечает за HOME. Без компьютера: «Настройки телевизора → Приложения → Mono TV →
Удалить». Никаких следов в системе не остаётся — приложение ничего в ней не меняло.

## 4. Как изменить Dock

**С пульта.**

- Наведите фокус на карточку в Dock или в «Приложениях», **удерживайте OK** (или нажмите MENU):
  «Переместить», «Добавить в Dock» / «Убрать из Dock», «Скрыть», «О приложении».
- «Переместить» поднимает карточку — двигайте стрелками, OK фиксирует.
- «Настройки → Dock»: количество элементов (4, 5, 6 или 7), состав, порядок, сброс к автоматическому.

**Автоматический Dock.** Пока вы ничего не меняли, Dock собирается сам: YouTube, Netflix, HBO Max,
Apple TV, Spotify, затем российские сервисы — из тех, что **реально установлены**; свободные места
занимают недавно использованные приложения. Пустых карточек не бывает.

**Через файл конфигурации.** Порядок автоматического Dock задаёт массив `dockPriority` в
`app/src/main/assets/launcher-config.json`. Менять его можно без пересборки: положите свой
`launcher-config.json` в папку приложения на телевизоре — он заменит встроенный.

```bash
adb push launcher-config.json /sdcard/Android/data/tv.monotv.launcher/files/launcher-config.json
```

Формат и все идентификаторы — в [docs/PACKAGES.md](docs/PACKAGES.md). Файл с ошибкой игнорируется, и
используется встроенный.

## 5. Как изменить обои (wallpaper)

«Настройки → Оформление → Обои»:

- **Динамические** (по умолчанию) — фон следует за выбранной карточкой Hero и плавно перетекает;
- шесть встроенных: Сияние, Дюны, Горизонт, Туманность, Хребет, Прилив;
- **Свой файл** — картинка `wallpaper.jpg` (или `.png`, `.webp`) в папке приложения:

```bash
adb push my-wallpaper.jpg /sdcard/Android/data/tv.monotv.launcher/files/wallpaper.jpg
```

  Без компьютера файл можно положить туда файловым менеджером телевизора с флешки. Заменили файл — выберите
  «Свой файл» ещё раз, и приложение перечитает его.

Достаточно 1920×1080: интерфейс и на 4K-панелях рисуется в 1080p, а большие картинки приложение само
уменьшит при загрузке. Лучше всего смотрятся тёмные изображения со спокойной левой и нижней частью — там
расположены текст и Dock.

Там же: акцентный цвет, тёмная тема («Чёрная» для OLED или «Графит»), интенсивность анимаций. Встроенные
обои сгенерированы скриптом `tools/art/generate_art.py`.

## 6. Как добавить приложение

Ничего делать не нужно: Mono TV сам находит всё, что поддерживает Android TV (категория
`LEANBACK_LAUNCHER`), а также приложения Сбера с их собственной категорией
`ru.sberdevices.category.STAR_LAUNCHER`. Установили приложение — оно сразу появилось в «Приложениях».

- Приложение рассчитано на телефон и не видно? «Настройки → Приложения → Приложения без TV-режима».
- Нужно в Dock? Удерживайте OK на карточке → «Добавить в Dock».
- Мешает? Удерживайте OK → «Скрыть». Вернуть: «Настройки → Приложения → Показывать и скрывать».
- Хотите, чтобы оно попадало в *автоматический* Dock и имело подпись в Hero, — добавьте запись в
  `launcher-config.json` (пример в [docs/PACKAGES.md](docs/PACKAGES.md), раздел 5).

## 7. Как вернуть стандартный Home

По умолчанию возвращать нечего: Mono TV не занимает роль HOME. Если вы включали её, есть четыре способа
отката, от простого к радикальному.

1. **В приложении:** «Настройки → Система → Вернуть стандартный домашний экран».
2. **Скриптом:**

   ```bash
   scripts/restore-home.sh
   ```

3. **Вручную через ADB** (скрипт делает то же самое):

   ```bash
   adb shell cmd package set-home-activity ru.sberdevices.starlauncher/.ui.mainscreen.MainActivity
   ```

   ```bash
   adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
   ```

4. **Удалить приложение** (с пульта через настройки телевизора или `adb uninstall tv.monotv.launcher`) —
   HOME вернётся к штатному экрану сам, потому что штатный экран никогда не отключался.

Сброс телевизора к заводским настройкам для отката **не нужен**.

### Как сделать Mono TV домашним экраном (осознанно, после проверки)

Делайте это только после того, как приложение поработало у вас как обычное: проверены пульт, BACK, запуск
приложений, входы, перезагрузка.

- В приложении: «Настройки → Система → Сделать домашним экраном» → подтвердить. Затем нажмите HOME и
  выберите Mono TV, если система спросит.
- Через ADB, с проверкой результата и обязательным подтверждением:

  ```bash
  scripts/set-home.sh
  ```

Чего делать **нельзя**: отключать или удалять штатный лаунчер (`pm disable-user`, `pm uninstall`). На части
прошивок Сбера это приводит к циклической перезагрузке или recovery, а сервис платформы всё равно включает
его обратно. Mono TV рассчитан на сосуществование со штатным экраном.

Известный побочный эффект смены HOME на некоторых моделях: кнопки-ярлыки пульта («ТВ», RUTUBE)
обрабатывает штатный лаунчер, и при другом HOME они могут перестать реагировать.

## Управление пультом

| Кнопка | Действие |
|---|---|
| ← → | движение внутри секции (Dock, ряд, сетка, пилюли) |
| ↑ ↓ | переход между секциями: панель → Hero → Dock → «Продолжить просмотр» → «Приложения» |
| OK | открыть |
| OK (удерживать) / MENU | меню приложения: переместить, в Dock / из Dock, скрыть |
| BACK | назад: закрыть меню → вернуться к Dock → выйти (если Mono TV не домашний экран) |
| HOME | системный Home |
| Ассистент | системный ассистент «Салют» (приложение кнопку не трогает) |

Навигация детерминирована: фокусом управляет не система, а одна чистая функция
(`nav/NavReducer.kt`), поэтому фокус не может «потеряться», пустые секции пропускаются, а каждая секция
помнит последний выбранный элемент.

## Настройки лаунчера

Пилюля «Настройки» в правом верхнем углу. Слева остаётся живой экран — изменения видны сразу.

- **Оформление** — тёмная тема, обои, акцентный цвет, анимации (Авто / Полные / Упрощённые / Выключены),
  демо-контент.
- **Dock** — количество (4–7), состав, порядок, сброс.
- **Приложения** — показывать / скрывать, порядок, приложения без TV-режима, сброс.
- **Система** — устройство, версия Android, экран, память, версия лаунчера, текущий домашний экран,
  системные настройки, отчёт об устройстве, роль домашнего экрана.

## «Продолжить просмотр»

У стороннего лаунчера нет доступа к истории просмотра внутри чужих приложений, поэтому ряд собирается
честно, из двух источников:

1. **Watch Next** — то, что приложения сами публикуют в системный TV-провайдер (с настоящим прогрессом).
   Читать чужие записи можно только с разрешением `READ_TV_LISTINGS`. Выдать его можно в приложении:
   «Настройки → Система → „Продолжить просмотр“ из приложений», а если прошивка не показывает системный
   запрос — через ADB:

   ```bash
   adb shell pm grant tv.monotv.launcher android.permission.READ_TV_LISTINGS
   ```

   Публикуют ли данные приложения на вашей прошивке, зависит от них самих.
2. **Недавно открытые приложения** — запасной вариант. Прогресс-бар для них не рисуется: приложение
   никогда не выдумывает прогресс.

Обложки по сети не загружаются (у приложения нет доступа в интернет): берётся локальная картинка из
провайдера или баннер приложения. «Демо-контент» в настройках добавляет вымышленные карточки для
демонстрации.

## Входы (HDMI / AV)

Пилюля «Входы» показывает список из стандартного TV Input Framework (`TvInputManager`): HDMI 1–3, AV,
эфирное ТВ — с состоянием «подключён / нет сигнала». Переключение — только документированным способом:
`ACTION_VIEW` на passthrough-URI входа, который обрабатывает системное TV-приложение
(на Сбер ТВ — `ru.sberdevices.tvinputs`). Vendor-команды и недокументированные интенты не используются.

Если прошивка входы не отдаёт, меню показывает список-заглушку с пометкой «Недоступно». Точка расширения
для будущих vendor-реализаций — интерфейс `InputSwitcher` в `data/inputs/AndroidInputsRepository.kt`.

## Производительность

Цель — 60 FPS на Mali-G31 и 1–2 ГБ памяти.

- **Нет runtime-blur.** «Матовое стекло» Dock — это заранее размытая копия фона 64×36 px, растянутая под
  панель: ноль затрат на кадр, работает на любом Android.
- **Нет бесконечных анимаций, видеофона, опросов сети и таймеров.** Часы идут по системному
  `TIME_TICK`, список приложений обновляется по широковещательным событиям пакетов.
- Анимации читаются в фазе отрисовки (`graphicsLayer`) и не вызывают рекомпозицию.
- Картинки декодируются вне главного потока под размер карточки, кэш ограничен по памяти; компонуются и
  загружаются только карточки рядом с видимой областью.
- На слабых устройствах (мало памяти, low-RAM) эффекты упрощаются автоматически; вручную —
  «Настройки → Оформление → Анимации».
- После установки `scripts/install.sh` выполняет AOT-компиляцию приложения.

Интерфейс свёрстан на «холсте» 960×540 dp и масштабируется под любое разрешение и плотность
(1280×720, 1920×1080, 3840×2160, ультраширокие панели), с отступами под overscan.

## Устройство проекта

```
app/src/main/kotlin/tv/monotv/launcher/
  core/      модели, UiState, конфигурация, правила Dock и сортировки (чистый Kotlin)
  nav/       модель навигации, NavReducer, каталоги настроек и меню
  input/     RemoteKeyMapper — кнопки пульта → NavKey
  data/      репозитории: приложения и картинки, настройки, система, входы, контент
  ui/        тема, компоненты, главный экран, оверлеи (Compose, без Material)
  LauncherViewModel.kt, MainActivity.kt, AppContainer.kt
app/src/main/assets/launcher-config.json   конфигурация лаунчера
scripts/     analyze-device, build, install, uninstall, set-home, restore-home, screenshot, verify-dpad
docs/        PACKAGES.md, DEVICE-ANALYSIS.md, скриншоты
tools/art/   генератор обоев и иконки
```

Стек: Kotlin, Jetpack Compose (foundation + animation, без Material-компонентов и сторонних библиотек),
minSdk 23, targetSdk 36.

## Подпись APK

Сборки подписываются ключом `keystore/sideload.jks`, который намеренно лежит в репозитории: приложение
распространяется только sideload-установкой, а постоянный ключ позволяет обновлять его поверх старой
версии без потери настроек. Для публикации где-либо используйте собственный ключ через переменные
`MONOTV_KEYSTORE`, `MONOTV_KEYSTORE_PASSWORD`, `MONOTV_KEY_ALIAS`, `MONOTV_KEY_PASSWORD`.

## Что проверено, а что нет

Проверено в среде разработки:

- сборка debug и release APK, подпись, содержимое манифеста;
- юнит-тесты: навигация (включая fuzz-тест на случайных последовательностях кнопок), правила Dock и
  сортировки, обработка кнопок пульта, ViewModel целиком, разбор конфигурации, форматирование часов;
- запуск всего приложения под Robolectric на API 28 / 30 / 33 / 34 с настоящими `KeyEvent`;
- рендер настоящего интерфейса в PNG для всех экранов и состояний, в 720p, 1080p, 2160p и 21:9.

**Не проверено — нужен ваш телевизор:**

- установка и запуск на реальной прошивке, фактическая плавность анимаций;
- работа настоящего пульта, включая долгое нажатие OK;
- переключение HDMI-входов;
- наличие данных Watch Next;
- поведение при назначении домашним экраном и после перезагрузки.

Порядок действий на телевизоре: анализ устройства → установка как обычного приложения →
`scripts/verify-dpad.sh` и ручная проверка → только потом, по желанию, роль HOME.
